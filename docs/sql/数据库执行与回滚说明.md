# 数据库执行与回滚说明（V1 基线）

## 1. 适用范围

- 适用脚本：`docs/db_init.sql`
- 数据库：MySQL 8.0+
- 目标：一次性完成 V1 基线建库

## 2. 执行前检查

- 确认当前连接的是目标环境（建议先 `dev`）
- 确认账号具备建表、删表、索引、外键权限
- 确认当前库允许执行清库重建（脚本包含 `DROP TABLE IF EXISTS`）
- 建议先备份现有数据

## 3. 一键执行命令

```bash
mysql -uroot -p -h127.0.0.1 your_db_name < docs/db_init.sql
```

若你希望在命令里指定字符集：

```bash
mysql --default-character-set=utf8mb4 -uroot -p -h127.0.0.1 your_db_name < docs/db_init.sql
```

## 4. 执行后校验

### 4.1 表数量与关键表存在性

```sql
SHOW TABLES;
```

重点确认以下表存在：

- `app_user`
- `role`
- `user_role`
- `dish`
- `ingredient`
- `menu_template`
- `menu_template_dish`
- `cooking_session`
- `session_dish`
- `prep_item`
- `cook_event`
- `session_retrospective`
- `session_review`

### 4.2 字段校验（关键增量）

```sql
DESC app_user;
DESC dish;
DESC ingredient;
DESC prep_item;
```

重点确认字段：

- `app_user.phone`
- `dish.is_deleted`
- `ingredient.protein_g_per_100g`
- `ingredient.fat_g_per_100g`
- `ingredient.carb_g_per_100g`
- `prep_item.is_shortage`

### 4.3 约束校验（点评表）

```sql
SHOW CREATE TABLE session_review;
```

确认包含：

- 外键：`session_id -> cooking_session.id`
- 外键：`dish_id -> dish.id`
- CHECK 约束：评分范围与 `retry_intent` 枚举

## 5. 常见失败与处理

- 外键报错：先确认执行顺序为单次跑 `db_init.sql`，不要拆段执行
- 权限不足：使用具备 DDL 权限的账号，或让 DBA 授权
- CHECK 不生效：确认 MySQL 版本 >= 8.0
- 字符集异常：使用 `--default-character-set=utf8mb4`

## 6. 回滚策略

`db_init.sql` 是“重建式”脚本，建议使用“库级回滚”：

1. 若为开发环境：
   - 直接重新执行 `docs/db_init.sql` 回到基线
2. 若为测试/预发环境：
   - 先恢复执行前备份
   - 再按最新脚本重放
