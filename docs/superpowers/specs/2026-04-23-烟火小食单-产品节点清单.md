## 3. 手工检查记录

### 3.1 初检失败点

- 发现“菜单模板维护”与“模板”存在命名混用，语义相同但命名不统一，存在后续重复建 ID 风险。
- 发现“烹饪记录”主节点已编号，但其“复盘结论”未独立编号，不满足 `V1 必做` 全覆盖要求。

### 3.2 修复动作

- 统一命名为“菜单模板维护”，并固定 ID 为 `P-MENU-001`。
- 为“复盘结论沉淀”补充分配 `P-COOK-004`，补齐烹饪记录域覆盖。

### 3.3 复检结果

- 复检通过：ID 格式统一、无重复、同名不重复，且 `V1 必做` 核心节点全部具备 ID，可直接进入 Task2 的研发拆分引用。
