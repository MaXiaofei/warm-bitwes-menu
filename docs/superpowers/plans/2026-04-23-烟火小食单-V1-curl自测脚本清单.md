## 0. 一次性准备

### 0.1 环境变量

```bash
export BASE_URL="http://localhost:8080/menu/api"
```

### 0.2 JSON 解析辅助（python3）

```bash
json_get() { python3 -c "import sys,json; d=json.load(sys.stdin); print(eval(sys.argv[1],{}, {'d':d}))" "$1"; }
```

> 使用示例：`TOKEN=$(curl ... | json_get "d['data']['accessToken']")`

## 1. P0 / Batch 1（健康 + AUTH + DISH + INGR + 字典）

### 1.1 健康检查（白名单）

```bash
curl -s "$BASE_URL/health"
```

### 1.2 登录获取 Token（若接口暂未实现，可临时跳过并放开鉴权用于联调）

```bash
LOGIN_RES=$(curl -s -X POST "$BASE_URL/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}')
echo "$LOGIN_RES"
TOKEN=$(echo "$LOGIN_RES" | json_get "d['data']['accessToken']")
echo "TOKEN=$TOKEN"
```

### 1.3 新增菜品 + 查询详情

```bash
DISH_CREATE_RES=$(curl -s -X POST "$BASE_URL/dishes" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"番茄炒蛋","durationMin":10,"difficulty":2}')
echo "$DISH_CREATE_RES"
DISH_ID=$(echo "$DISH_CREATE_RES" | json_get "d['data']['id']")
echo "DISH_ID=$DISH_ID"

curl -s "$BASE_URL/dishes/$DISH_ID" -H "Authorization: Bearer $TOKEN"
```

### 1.4 菜品分页

```bash
curl -s "$BASE_URL/dishes?pageNum=1&pageSize=10" -H "Authorization: Bearer $TOKEN"
```

### 1.5 新增食材 + 查询详情

```bash
ING_CREATE_RES=$(curl -s -X POST "$BASE_URL/ingredients" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"鸡蛋","unit":"个","caloriesKcalPer100g":143.0,"giValue":0.0}')
echo "$ING_CREATE_RES"
ING_ID=$(echo "$ING_CREATE_RES" | json_get "d['data']['id']")
echo "ING_ID=$ING_ID"

curl -s "$BASE_URL/ingredients/$ING_ID" -H "Authorization: Bearer $TOKEN"
```

### 1.6 食材分页

```bash
curl -s "$BASE_URL/ingredients?pageNum=1&pageSize=10" -H "Authorization: Bearer $TOKEN"
```

## 2. P1 / Batch 2（关联 + 模板 + 会话）

### 2.1 维护菜品-食材关联

```bash
curl -s -X PUT "$BASE_URL/dishes/$DISH_ID/ingredients" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"items\":[{\"ingredientId\":$ING_ID,\"amountG\":200,\"sortOrder\":0}]}"
```

### 2.2 新增菜单模板 + 详情

```bash
TPL_CREATE_RES=$(curl -s -X POST "$BASE_URL/menu-templates" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"家常两菜\",\"templateType\":4,\"dishIds\":[$DISH_ID]}")
echo "$TPL_CREATE_RES"

curl -s "$BASE_URL/menu-templates/$TPL_ID" -H "Authorization: Bearer $TOKEN"
```

### 2.3 模板食材汇总

```bash
curl -s "$BASE_URL/menu-templates/$TPL_ID/ingredient-summary" -H "Authorization: Bearer $TOKEN"
```

### 2.4 创建做饭会话

```bash
SESSION_CREATE_RES=$(curl -s -X POST "$BASE_URL/cook-sessions" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \

SESSION_ID=$(echo "$SESSION_CREATE_RES" | json_get "d['data']['sessionId']")

```
