# 烟火小食单产品版到研发版拆分 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已确认的产品版信息架构稳定拆分为可研发执行的版本（模块、接口、数据对象、验收项），并形成可追踪映射。

**Architecture:** 采用“产品节点唯一标识 + 研发五段拆分”方法，先建立映射骨架，再按共享能力优先、双端消费跟进的顺序落地。过程以文档和脑图结构变更为主，不直接进入业务代码实现。

**Tech Stack:** XMind 脑图、Markdown 文档、Maven 多模块项目结构（`boot/controller/service/mapper/common`）
