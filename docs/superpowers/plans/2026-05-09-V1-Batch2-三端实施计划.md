# V1 Batch2 三端实施计划（主链路组装）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 **V1.0-Batch2**：覆盖 `docs/superpowers/plans/2026-04-23-烟火小食单-V1-研发执行批次.md` 中 **Batch 2** 的目标模块、交付物与三条验收检查点；三端采用既有策略「**后端先行、同批联调**」（见 `docs/superpowers/specs/2026-05-09-三端开发进度与版本规划-design.md`）。本文**不依赖** Git 远端对齐状态，仅假定可在各仓库工作树内开发与联调。

**Architecture:** 后端继续 Spring Boot 多模块；`menu-admin` 在现有路由与鉴权上增量加页；`menu-mini` 在 Tab/页面栈上增加 Batch2 流程。权威产品节点仍引用 `docs/superpowers/specs/2026-04-23-烟火小食单-产品节点清单.md` 中 `P-MENU-*`、`P-COOK-*` 等 ID。

**Tech Stack:** 与三仓现状一致：Java 17 + Spring Boot + MyBatis；Vue3 + Vite + Element Plus；uni-app + Vue3 + Vite + Vitest。

**Batch2 官方验收检查点（必须全部可演示/可自动校验）：**

1. 菜品食材关联后，**模板食材汇总**接口能正确聚合数量。  
2. 会话创建满足 **「菜单/模板二选一 + 开始时间必填」**（与当前仅 `templateId` 必填的实现对齐或调整实现与文档择一）。  
3. **会话时间线、历史查询、复盘提交** 形成可回看闭环（见下文「差距」：表结构已部分具备，HTTP 与小程序/管理端 UI 多未齐）。

## 0. 现状与差距（只读盘点，实施前先完成）

下表用于避免重复造轮子；若与代码不一致，以 **仓库内实现 + `docs/db_init.sql`** 为准并更新本表。

| 模块（产品 ID） | 后端现状（概括） | 管理端 / 小程序 |
|-----------------|------------------|-----------------|
| 菜品-食材关联 `P-INGR-004` | `PUT /api/dishes/{id}/ingredients` 等已存在 | 管理端：菜品维度的关联编辑需在 Batch2 **交互上与汇总链路打通并回归**；小程序：只读即可 |
| 菜品图文 `P-DISH-005` | `DishDetail`/`steps` 等字段已贯通详情 VO | 管理端：**步骤/封面编辑表单**与预览；小程序：详情展示 |
| 菜单模板 `P-MENU-001`～004 | `MenuTemplateController`：`POST` 创建、`GET` 分页/详情、`GET .../ingredient-summary`；模板含 `templateType/scene/crowd` 等字段 | **缺**：模板列表筛选、编辑、绑定菜品 UI；汇总页对接 |
| 烹饪会话 `P-COOK-001`～004 | `CookSessionController`：`POST /api/cook-sessions` 创建；**另**：`prep-list/generate`、`reviews` 等更接近 Batch3，Batch2 关门时需约定是否 **对前端隐藏或 feature-flag** | **缺**：小程序创建会话、会话详情；过程事件/复盘 **REST 层多处缺失**（见下） |

**已发现的硬性差距（需在 Batch2 内收口）：**

1. **会话创建契约**：`CookSessionCreateReq` 当前 **`templateId` 必填**，与验收「模板或自选菜单二选一」不一致；`cooking_session.template_id` 在 DDL 中可为 NULL，具备扩展空间。  
2. **过程 / 复盘 API**：`docs/db_init.sql` 已定义 `cook_event`、`session_retrospective` 等表，但代码库中 **未见** `CookEvent` Mapper/Controller 与复盘写入接口，无法满足验收第 3 条闭环。  
3. **权限点**：Batch2 新增接口需补齐权限常量、拦截器映射及 **Swagger 注释**，与管理端路由 `meta` 对齐。
