# 烟火小食单研发拆分矩阵（Task2）

## 1. 适用范围

- 本矩阵用于将产品节点清单中的 `V1 必做` 核心域拆分为可研发执行项。
- 本次覆盖域：`AUTH`、`DISH`、`INGR`、`MENU`、`COOK`、`REVIEW`、`PREP`。
- 追踪原则：产品节点语义不变则 ID 不变，研发项必须引用原产品 ID。

## 2. 矩阵列定义

- 产品ID：产品节点唯一标识，格式 `P-<DOMAIN>-NNN`。
- 研发模块：后端实现归属模块（可对应 `controller/service/mapper` 聚合边界）。
- API列表：最小可执行接口集合（方法 + 路径）。
- 数据对象：接口及持久化涉及的核心对象（DTO/Entity/VO）。
- 校验/异常：关键参数校验与业务异常口径（统一异常处理）。
- 验收口径：可验证的完成标准（联调与回归依据）。
